> kaydedip tekrar kullanabilirsiniz.

## ⬇️ Windows kurulumu

1. **Windows için İndir** butonuna tıklayın.
2. İnen **`ilksms-eokul-Setup.exe`** dosyasına çift tıklayın, kurulum kendiliğinden tamamlanır.
3. Masaüstündeki **İlksms - Eokul Entegrasyonu** kısayolundan açın.

> 💡 Windows "Bilinmeyen yayıncı" uyarısı verirse **Daha fazla bilgi → Yine de çalıştır** deyin.

## 🐧 Pardus / Linux kurulumu

1. **Pardus / Linux için İndir** butonuna tıklayın.
2. İnen **`ilksms-eokul-Setup.AppImage`** dosyasını **ev dizininize** taşıyın (Masaüstü, Belgeler veya İndirilenler olur).
3. Dosyaya **sağ tıklayın → Özellikler → İzinler** sekmesi → **"Dosyanın program olarak çalıştırılmasına izin ver"** kutusunu işaretleyin.
4. Çift tıklayıp açın. Uygulama ilk açılışta kendini **uygulama menüsüne** ekler, sonraki açılışlarda oradan başlatabilirsiniz.

> 💡 Üçüncü adım Linux'un güvenlik davranışıdır: indirilen dosyalara çalıştırma izni kendiliğinden verilmez.
> Bir kez yapılır, sonrasında tekrar sorulmaz.

> [!IMPORTANT]
> Dosyayı **USB bellekten veya ağ/paylaşılan klasörden çalıştırmayın**; bu konumlar çalıştırma iznini
> kabul etmediği için uygulama açılmaz. Önce bilgisayara kopyalayın.

Kurulum için yönetici parolası gerekmez. Bağımlılık kurmanız, depo eklemeniz de gerekmez —
tek dosya kendi başına çalışır.

## ▶️ Nasıl çalışır?

- Uygulama açılınca **MEBBİS giriş ekranı** gelir; kendi MEBBİS bilgilerinizle giriş yaparsınız.
- Giriş yaptıktan sonra e-Okul işlemleriniz uygulama içinden yürür.
- İşlemler doğrudan **sizin bilgisayarınızdan** yapılır.

## 🔄 Otomatik güncelleme

Uygulama her açılışta yeni sürümü **kendisi kontrol edip kurar** — tekrar indirmenize gerek yoktur.
Yeni sürüm çıktığında bir dahaki açılışta otomatik gelir. Pardus ve Linux tarafında güncelleme
yönetici parolası da istemez.
